## ℹ️ Overview

This project was mostly a followed tutorial I went through from a book I purchased. This book being from [nnfs.io](https://nnfs.io/). It goes through all the necessary procedures and calculation regarding Neural Networks. I highly recommend this book to anybody wanting to understand the building blocks for Neural Networks.

Anyways, the book's main Neural Network is a classifier for three distinct Spiral Functions. All in which the model will try to classify (x,y) points that correspond to a Spiral Function. 

### Architecture 

For my fellow beginner Machine learning nerds, the models architecture is a **2 - 64 - 1** layer model Neural Network. As of now the activation function is just a basic **ReLu (Rectified Linear Units)** and **sigmoid** function, with the loss being calculated with a **Binary Cross entropy** function.

The architecture will definitely change in future based on what I want the model to do next.
